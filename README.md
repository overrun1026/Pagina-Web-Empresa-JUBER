## 📌 Sobre el proyecto

**Juver** es un sitio web corporativo desarrollado para ofrecer a la empresa una presencia digital moderna, profesional y accesible.

El proyecto busca proporcionar a los visitantes una experiencia clara e intuitiva para conocer la empresa, sus servicios, información relevante y diferentes canales de contacto.

## 🚀 Instalación

### 1️⃣ Clonar el repositorio

```bash
git clone git@github.com:overrun1026/juver-pagina-web.git
```

### 2️⃣ Acceder al proyecto

```bash
cd juver-pagina-web
```

### 3️⃣ Ejecutar el sitio

Puedes abrir directamente:

```text
index.html
```

También puedes utilizar un servidor local para obtener una experiencia de desarrollo más completa.
